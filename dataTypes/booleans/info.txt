--------- Booleans-----------

True and False values for decisions

What are Booleans

Booleans are the simplest data types - they can only True or Flase.  Think of them as yes / no answers

is_logged_in = True
is_admin = Flase
has_permission = True

===== Comparison Operators ======

These operators compare values and return True or False

age = 25
# Equality

print(age == 25) # True Equals
print(age != 30) # True - not equals 

# Greater / Less than
print(age > 20) # True - greater than
print(age < 30) # True - Less than
print(age >= 25) # True - Greater or equals
print(age <= 25) # True - less or equal
