What are if statement ?

if statement let your program make decisions. They check if something is true or false, Then act accordingly

Real - life Logic

> IF it's raining THAN take umbrela
> IF battery < 20% THEN charge allows phone
> IF Password correct THEN allow access

__________________________________________________________________________________

Common mistake 

-- Forgetting the colon

> # Wrong
if x > 5
    print("Big")

# Right
if x > 5:
    print("Big")

-- Using = instead of ==

# Wrong (assignment)
if x = 5:
    print("Five")

# Right (comparison)
if x == 5:
    print("Five")

-- Wrong indentation

# Wrong
if True:
print("Hello")  # IndentationError

# Right
if True:
    print("Hello")
