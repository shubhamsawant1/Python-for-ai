What is Packages 
packages are collection of python-code that slove specific problems:

> request - Download web pages and dada
> pandas - work with spreadsheet and data
> numpy - Fast mathematical operations
> openai - Connect to AI models
> beautifulsoup4 - Extract data from website

Each package is like a toolbox with specialized tools for a specific job.

Meet pip

pip ( pip install packages) is python's packages manager. it 

> download packages from the internet
> install them in your enviroment 
> Manages versions and dependencies
